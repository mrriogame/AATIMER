# GitHub Pages — статический таймер событий

## Локальный просмотр

Из папки `timer-site` нужен любой статический сервер (модули ES и `fetch` к JSON не работают через `file://`):

```bash
cd timer-site
python -m http.server 8080
```

Откройте http://localhost:8080

## Публикация на GitHub Pages

1. Залейте содержимое этой папки в репозиторий (корень или `/docs`).
2. Settings → Pages → Deploy from branch → выберите папку.
3. Если сайт не в корне репозитория (например `username.github.io/repo/`), пути уже относительные (`./`), должны работать.

## Что сохраняется в браузере (LocalStorage)

- `eventsSubscribed` — включённые будильники по id события  
- `eventsNotify` / `eventsNotifyMinutes` — глобальные уведомления  
- `eventsCollapsed` — свёрнутые категории  

Ключи совместимы со старым PHP-сайтом.

Уведомления срабатывают, пока открыта вкладка/PWA. Подписки после закрытия браузера восстанавливаются при следующем заходе.
